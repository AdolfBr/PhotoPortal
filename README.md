# PhotoPortal

PhotoPortal — настольное приложение на Python/Tkinter для съёмки или загрузки
фотографии, удаления фона, кадрирования в пропорции 3:4 и сохранения результата.

## Что понадобится

- Windows 10/11 (приложение использует системные пути Windows и открывает папку
  сохранения через Windows Explorer);
- Python 3.10 или 3.11, 64-bit;
- PyCharm Community или Professional;
- веб-камера для проверки съёмки (загрузку готового изображения можно проверить
  без камеры).

> Python 3.10/3.11 рекомендуется ради совместимости с бинарными пакетами
> MediaPipe и OpenCV. При установке Python включите пункт **Add Python to PATH**.

## Как открыть проект в PyCharm

1. Скачайте репозиторий и распакуйте его, либо клонируйте через
   **Git → Clone** в PyCharm.
2. На стартовом экране PyCharm нажмите **Open** и выберите папку `PhotoPortal`,
   в которой находятся `PhotoPortal.py` и `requirements.txt`.
3. Откройте **File → Settings → Project: PhotoPortal → Python Interpreter**.
4. Нажмите **Add Interpreter → Add Local Interpreter → Virtualenv**.
5. Выберите установленный Python 3.10/3.11 как **Base interpreter**, оставьте
   расположение `.venv` и нажмите **OK**.
6. Откройте встроенный терминал PyCharm (**View → Tool Windows → Terminal**) и
   установите зависимости:

   ```powershell
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   ```

Если PyCharm показывает жёлтую панель с предложением установить зависимости из
`requirements.txt`, можно нажать **Install requirements** вместо второй команды.

## Как запустить

### Быстрый способ

Откройте `PhotoPortal.py`, нажмите правой кнопкой в редакторе и выберите
**Run 'PhotoPortal'**. При первом запуске разрешите Python доступ к камере, если
Windows покажет соответствующий запрос.

### Постоянная конфигурация запуска

1. Откройте **Run → Edit Configurations** и нажмите **+ → Python**.
2. Укажите:
   - **Name:** `PhotoPortal`;
   - **Script path:** полный путь к `PhotoPortal.py`;
   - **Working directory:** корневая папка проекта `PhotoPortal`;
   - **Python interpreter:** созданный ранее `.venv`.
3. Нажмите **Apply**, затем **Run**.

То же самое можно выполнить из терминала, находясь в корне проекта:

```powershell
python PhotoPortal.py
```

После запуска приложение создаёт конфигурацию `PhotoPortal_config.ini`, журнал
`PhotoPortal.log` и временную папку `PhotoPortal\Temp` в `%LOCALAPPDATA%`.
Папку сохранения и камеру можно изменить кнопкой **⚙** в приложении.

## Как проверить

### Автоматические тесты

Во встроенном терминале PyCharm выполните:

```powershell
python -m unittest discover -s tests -v
```

Успешная проверка заканчивается строкой `OK`. Тесты не требуют настоящей камеры.
Также можно нажать правой кнопкой на папке `tests` и выбрать **Run
'Unittests in tests'**.

### Ручная проверка приложения

1. Запустите `PhotoPortal.py` и убедитесь, что главное окно открылось без ошибки.
2. Проверьте, что виден кадр с выбранной камеры. Если камеры нет, предупреждение
   ожидаемо — используйте кнопку **Загрузить свое фото**.
3. Сделайте снимок либо загрузите JPG/PNG, выберите область кадрирования и
   подтвердите её.
4. Измените яркость и мягкость краёв, затем нажмите **Сохранить**.
5. Убедитесь, что в выбранной папке появился JPEG размером 600×800 пикселей.
6. Откройте настройки кнопкой **⚙**, измените параметр, примените его и
   перезапустите приложение: настройка должна сохраниться.

## Частые проблемы

- **`No module named cv2/PIL/mediapipe`** — выбран не тот интерпретатор либо не
  установлены зависимости. Проверьте `.venv` в строке состояния PyCharm и снова
  выполните `python -m pip install -r requirements.txt`.
- **Камера не найдена/не открывается** — закройте приложения, уже использующие
  камеру, и разрешите доступ в **Параметры Windows → Конфиденциальность и
  безопасность → Камера**.
- **Не устанавливается MediaPipe** — проверьте, что используется 64-битный
  Python 3.10 или 3.11, а не 32-битная либо слишком новая версия Python.
- **Иконка не найдена** — это не мешает работе из исходников. Путь к `.ico`
  предназначен для установленной версии приложения и записывается в настройках.
